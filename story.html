Three engines, one stack

What each layer needs, what it outputs, and how much of it this prototype actually runs versus simulates.

01Cost · floor engine

Inputs
Seller: purchase cost, GST status. Meesho: shipping by weight slab, category RTO and return rates, unsellable share.
Output
One floor price, recomputed when any input moves, shown right beside the price field.
In this prototype
Real math Formula is live and reproduces the deck's ₹345 for Ramesh. Rate tables are placeholders.

02Market · band engine

Inputs
Look-alike cluster (category, fabric, image embedding, attributes), orders by price over 30 days.
Output
Demand-weighted band, its width and 30-day drift, and where she sits in it.
In this prototype
Simulated One hard-coded kurti cluster; demand curve uses a constant elasticity of 5.

03Autopilot · lifecycle engine

Inputs
Six signals per listing per day, the seller's floor and ceiling, stage (reviews, organic share).
Output
At most one WhatsApp nudge a week, one tap to accept, one tap to undo.
In this prototype
Real rules Thresholds from deck slide 3 are evaluated live. Scripted The event data is a story.

Sahi Daam needs no new data collection. It reads tabs sellers already use and writes one number back into the price field.

Assumptions

  • Confirmed RTO orders are not charged to the seller; customer returns carry a return shipping fee (Meesho Supplier Panel tutorial). The floor model already works this way: an RTO costs only the goods lost to damage.
  • Check The actual forward and return shipping fee per weight slab, and whether forward shipping is deducted from the settlement or built into the customer price.
  • Check Commission is 0% and no other per-order platform fee applies.
  • Check GST on apparel under ₹2,500 is 5%, and registered sellers claim input credit on purchase.

What a production build would add

  • Demand curve learned per cluster from past price changes, instead of one fixed elasticity.
  • Autopilot price tests run as bandit experiments inside the seller's corridor, judged on contribution per 1,000 views.
  • Nudges through the panel's existing WhatsApp notifications, in the seller's language, capped at one a week.
  • Guardrail: autopilot can never publish a price below the floor.
